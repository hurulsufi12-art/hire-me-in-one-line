# Hire Me In One Line

A tiny Python program that writes a single sentence to `/output/entry.txt` for the make.fun bounty "Hire Me In One Line".

[![Competition](https://make.fun/badge/u-kiencx-hire-me-in-one-line-5a108081.svg)](https://make.fun/bounty/u-kiencx-hire-me-in-one-line-5a108081)
[![Rank](https://make.fun/badge/u-kiencx-hire-me-in-one-line-5a108081/hurulsufi12-art/hire-me-in-one-line/rank.svg)](https://make.fun/bounty/u-kiencx-hire-me-in-one-line-5a108081)
[![Reward](https://make.fun/badge/u-kiencx-hire-me-in-one-line-5a108081/hurulsufi12-art/hire-me-in-one-line/reward.svg)](https://make.fun/bounty/u-kiencx-hire-me-in-one-line-5a108081)

Run with `python3 main.py`. It writes exactly one sentence (140 characters, ASCII) to `/output/entry.txt`, with no trailing newline.
